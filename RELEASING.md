# Выпуск версии
1. Создайте ветку release/vX.Y.Z и Draft PR. В описании укажите изменения и ссылку на парный PR в [adv_yandex_xyin9](https://github.com/okaygoogle101/adv_yandex_xyin9).
2. Обновите VERSION.txt, CHANGELOG.md, ссылки README на конкретную версию. В готовом репозитории обновите cstrike; в исходном — соответствующие исходники MAP, WAD и плагина.
3. Соберите карту/плагин при необходимости, проверьте игру и последующие раунды. Не меняйте имена игровых файлов.
4. После проверки примите оба PR. Создайте в каждом репозитории одинаковый тег vX.Y.Z на соответствующем проверенном коммите.
5. Подготовьте оба релиза как черновики. В каждом укажите изменения, заменяемые файлы, необходимость обновления плагина и ссылку на релиз/тег другой стороны именно vX.Y.Z.
6. Прикрепите готовый ZIP к релизу карты, исходный ZIP к релизу исходников. Опубликуйте оба и проверьте взаимные ссылки.

v1.0.1 — исправления; v1.1.0 — новые возможности; v2.0.0 — крупные несовместимые изменения. Выпущенные теги не передвигайте: исправления получают новую версию.

## Соавторство

Автор проекта — okay_google; соавтор — Codex (ИИ-помощник OpenAI). Для изменений, подготовленных совместно с Codex, добавляйте в конец сообщения коммита после пустой строки:

```text
Co-authored-by: Codex <noreply@openai.com>
```

При объединении PR через squash сохраняйте эту строку в итоговом коммите. Для изменений без участия Codex подпись не нужна.
